## 搬瓦工切换机房的完整操作步骤

整个流程大约需要 10-20 分钟，操作本身只用 1 分钟。

### 第一步：登录搬瓦工官网，进入 KiwiVM 控制面板

打开搬瓦工官网，用账号密码登录后，点击顶部菜单的 **Services → My Services**，在列表中找到你要迁移的 VPS，点击旁边的 **KiwiVM Control Panel** 按钮进入。

### 第二步：先停机

在 KiwiVM 主界面，点击 **Stop** 按钮关闭 VPS。迁移前必须先关机，否则操作无法继续。

### 第三步：找到迁移机房的入口

在左侧菜单中，找到 **Migrate** 分区，点击 **Migrate to another DC**。

### 第四步：选择目标机房并确认

页面会显示你当前所在的机房，以及可以迁移的目标机房列表。从中选择你想要的机房，点击 **Confirm on next step**。

### 第五步：正式启动迁移

确认界面出现后，点击 **Start Migration**，系统开始迁移。

### 第六步：等待完成，收确认邮件

迁移通常需要 10-15 分钟，完成后你会收到一封包含新 IP 地址的邮件。收到邮件就代表迁移完成了。

## 切换机房之前，必须知道的 4 件事

### 1. 免费，次数不限，但会消耗流量

搬瓦工切换机房本身不收费，也没有次数上限。

但每次迁移都会消耗流量。根据实际测试，消耗的流量大约是 VPS 已用硬盘空间的 4-8 倍。举个例子：如果你的 VPS 里存了 5GB 的内容，一次迁移大约要消耗 20-40GB 流量。数据越多，迁移流量越大。

所以虽然没次数限制，但别把它当"随时换着玩"的工具——流量是真的在减。选好机房，测试满意了再迁，是更稳的做法。

### 2. IP 一定会换，数据一定保留

切换机房后，VPS 的 IP 地址会变成新机房的 IP。这是无法避免的。

好消息是：VPS 内部的所有内容——文件、系统配置、root 密码、运行中的程序数据——都会完整迁移过去。SSH 密码不变，只需要换个新 IP 连接就行。

如果你在 VPS 上建了网站，迁移完成后记得去域名服务商那里更新 A 记录，把域名解析更新到新 IP，网站才能正常访问。

### 3. IP 被封了，不能用切换机房来逃跑

这是很多人踩过的坑。

如果你的 VPS IP 被防火长城屏蔽了，KiwiVM 的迁移功能会自动禁用。尝试迁移时会反复报错：`Migration backend is currently not available for this VPS. (734152)`

这不是 bug，是搬瓦工的官方政策。切换机房的功能设计初衷是优化线路，不是绕过封锁换 IP。IP 被封之后唯一的官方解决方式是付费更换 IP（$8.79），而不是切机房。

## 切换机房后，记得做这两件事

迁移完成不等于万事大吉。

**第一件事：更新 SSH 连接信息。** 新机房的 IP 已经变了，打开你的 SSH 客户端，把连接的 IP 换成邮件里收到的新 IP，端口和密码不变。

**第二件事：更新域名解析（如果你在搬瓦工上建了网站）。** 去域名注册商的后台，把域名的 A 记录指向新 IP。解析生效通常需要几分钟到几小时不等，等 DNS 传播完成后网站就能正常访问了。

如果换了新 IP 之后网站还是打不开，大概率是 DNS 还没完全生效，等一会儿再试。
